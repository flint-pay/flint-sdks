## OrderTaxUpdateRequestInput

Changes to an order's tax settings: whether tax is enabled, the calculation, the location, and per-line-item or per-charge calculations.

Request input.

| Field | Presence | Type | Description |
| --- | --- | --- | --- |
| `calculation` | Optional | [OrderTaxCalculationRequestInput](../models/OrderTaxCalculationRequestInput.md#ordertaxcalculationrequestinput) | How tax is calculated: automatically through Flint's tax connection, or from components you supply. How tax is calculated on an order: automatically, or externally with the tax components you supply. |
| `charge_calculations` | Optional | Array of [OrderChargeTaxAssignmentInput](../models/OrderChargeTaxAssignmentInput.md#orderchargetaxassignmentinput) | Replace calculations for the listed components and keep unlisted calculations. Allowed only when the order uses external tax, including a switch in this request. Settled components cannot be changed. |
| `delivery_charge_calculation` | Optional | [DeliveryChargeTaxCalculationRequestModelInput](../models/DeliveryChargeTaxCalculationRequestModelInput.md#deliverychargetaxcalculationrequestmodelinput) or null | Percentage tax template copied onto every positive delivery charge generated by checkout, including paid pickup. Allowed only with external tax. Changing it leaves existing charges unchanged; use tax.charge_calculations to override those. A new selection copies the template again. Set it before issuing an invoice; the invoice freezes it with the order. Send null to clear it. |
| `enabled` | Optional | boolean | Whether Flint calculates tax for the order. When `false`, no tax applies. |
| `line_item_calculations` | Optional | Array of [OrderLineItemTaxAssignmentInput](../models/OrderLineItemTaxAssignmentInput.md#orderlineitemtaxassignmentinput) | Replace calculations for the listed components and keep unlisted calculations. Allowed only when the order uses external tax, including a switch in this request. Settled components cannot be changed. |
| `location` | Optional | [OrderTaxLocationRequestInput](../models/OrderTaxLocationRequestInput.md#ordertaxlocationrequestinput) | The address Flint calculates automatic tax at for items and charges without a fulfillment destination of their own. The tax location you supply for an order, as a postal code or a full address, with or without an address type. |

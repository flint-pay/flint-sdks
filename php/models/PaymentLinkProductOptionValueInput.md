## PaymentLinkProductOptionValueInput

A product option value used by an available payment link variant.

Request input.

| Field | Presence | Type | Description |
| --- | --- | --- | --- |
| `option_value_id` | Required | string | ID of the product option value. |
| `value` | Required | string | Product option value shown to the buyer, such as M or Blue. |

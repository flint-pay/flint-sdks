## CheckoutSessionWithSecret

The checkout session with any newly issued checkout credential. Hosted launches return url without checkout_auth_token. Headless launches return checkout_auth_token without url. Customer binding confirmation returns its newly issued credential for either surface.

A session in which a buyer completes an order's payment.

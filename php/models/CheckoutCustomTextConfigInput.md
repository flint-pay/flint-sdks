## CheckoutCustomTextConfigInput

Custom text shown in checkout: an order summary message and a shipping address label.

Request input.

| Field | Presence | Type | Description |
| --- | --- | --- | --- |
| `order_summary_message` | Optional | string | Message shown near the order summary in checkout. |
| `shipping_address_label` | Optional | string | Label shown for the shipping address in checkout. |

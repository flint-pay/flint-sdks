# Flint Public API models

[API reference](REFERENCE.md) · [Runtime guide](RUNTIME.md)

These classes expose presence-aware getters. Omitted optional response fields return null; has() distinguishes omission from present-null. Input classes omit read-only fields, and responses omit write-only fields. Integer counters such as version use int with a safe range of ±(2^53 − 1); values outside that range fail without rounding. Integers inside exact components (Money) remain exact strings. Money amounts stay exact strings when their component is listed. Sum money amounts with `bcadd($a->getAmount(), $b->getAmount(), 0)` (requires ext-bcmath). Decimal fields preserve exact numeric strings.

Schema defaults are metadata; clients do not apply them. Field definitions apply to all variants. Rules under each condition specify presence and additional constraints. Composed alternative groups apply together: satisfy a variant from each numbered group.

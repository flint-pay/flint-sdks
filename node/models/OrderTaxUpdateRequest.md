## OrderTaxUpdateRequest

Changes to an order's tax settings: whether tax is enabled, the calculation, the location, the exemption selection, and per-line-item or per-charge calculations.





| Field | Presence | Type | Description |
| --- | --- | --- | --- |
| `calculation` | Optional | [OrderTaxCalculationRequest](../models/OrderTaxCalculationRequest.md#ordertaxcalculationrequest) | How tax is calculated: automatically through Flint's tax connection, or from components you supply. How tax is calculated on an order: automatically, or externally with the tax components you supply. |
| `charge_calculations` | Optional | Array of [OrderChargeTaxAssignment](../models/OrderChargeTaxAssignment.md#orderchargetaxassignment) | Replace calculations for the listed components and keep unlisted calculations. Allowed only when the order uses external tax, including a switch in this request. Settled components cannot be changed. |
| `delivery_charge_calculation` | Optional | [DeliveryChargeTaxCalculationRequest](../models/DeliveryChargeTaxCalculationRequest.md#deliverychargetaxcalculationrequest) or null | Percentage tax template copied onto every positive delivery charge generated by checkout, including paid pickup. Allowed only with external tax. Changing it leaves existing charges unchanged; use tax.charge_calculations to override those. A new selection copies the template again. Set it before issuing an invoice; the invoice freezes it with the order. Send null to clear it. `delivery_charge_calculation`: [declared alternatives](../models/OrderTaxUpdateRequest.md#ordertaxupdaterequestdelivery_charge_calculation). |

When you send false, calculation, location, delivery_charge_calculation, exemption, and calculation assignments must be omitted. |

### OrderTaxUpdateRequest.delivery_charge_calculation

Percentage tax template copied onto every positive delivery charge generated by checkout, including paid pickup. Allowed only with external tax. Changing it leaves existing charges unchanged; use tax.charge_calculations to override those. A new selection copies the template again. Set it before issuing an invoice; the invoice freezes it with the order. Send null to clear it.

| Field | Presence | Type | Description |
| --- | --- | --- | --- |
| `components` | Conditional | Array of [TaxComponentRequest](../models/TaxComponentRequest.md#taxcomponentrequest) | The tax copied onto each delivery charge, one percentage component per jurisdiction and tax type. minItems: `1`. `components[]`: [field definitions](../models/DeliveryChargeTaxCalculationRequest.md#deliverychargetaxcalculationrequest-variant-2components). |
| `mode` | Conditional | string | Optional. If you send it, it must be `external`, because delivery charge templates apply only to orders that use external tax. Values: `"external"`. |
| `price_mode` | Conditional | string | Whether the delivery charge already includes the tax. Values: `"additive"`, `"inclusive"`. |

### OrderTaxUpdateRequest.delivery_charge_calculation variant 1: `mode` = `"external"`

- Optional: `mode`.

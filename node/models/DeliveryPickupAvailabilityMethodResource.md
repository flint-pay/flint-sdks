## DeliveryPickupAvailabilityMethodResource

A pickup delivery method, with its revision, that can serve a pickup location.





| Field | Presence | Type | Description |
| --- | --- | --- | --- |
| `delivery_method_id` | Required | string | ID of the pickup method. Example: `"dmet_01KEZF7C00YSG3X2D1TZJ36TM0"`. |
| `delivery_method_revision_id` | Required | string | ID of the method revision that was evaluated. Example: `"dmetr_01KEZF7C001ZF9D92DY1G51GV9"`. |

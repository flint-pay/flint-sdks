## PublicShopCategory

Category shown on the shop.





| Field | Presence | Type | Description |
| --- | --- | --- | --- |
| `category_id` | Required | string | Category ID. Example: `"ctg_01KEZF7C001T4WWBPVGWRZD88Q"`. |
| `handle` | Required | string | Category handle. |
| `name` | Required | string | Category name. |

## OrderTaxRequest

Tax settings you supply when creating an order: whether tax is enabled, how it is calculated, and the tax location.





| Field | Presence | Type | Description |
| --- | --- | --- | --- |
| `calculation` | Optional | [OrderTaxCalculationRequest](../models/OrderTaxCalculationRequest.md#ordertaxcalculationrequest) | How tax is calculated: automatically through Flint's tax connection, or from components you supply. How tax is calculated on an order: automatically, or externally with the tax components you supply. |
| `delivery_charge_calculation` | Optional | [DeliveryChargeTaxCalculationRequest](../models/DeliveryChargeTaxCalculationRequest.md#deliverychargetaxcalculationrequest) | Percentage tax template copied onto every positive delivery charge generated by checkout, including paid pickup. Allowed only with external tax. Changing it leaves existing charges unchanged; use tax.charge_calculations to override those. A new selection copies the template again. Set it before issuing an invoice; the invoice freezes it with the order. A percentage tax template for the delivery charges checkout generates, including paid pickup: whether the charge includes the tax, and the tax components. Allowed only on orders that use external tax. `delivery_charge_calculation`: [field definitions](../models/OrderTaxRequest.md#ordertaxrequestdelivery_charge_calculation). |
| `enabled` | Optional | boolean | Whether Flint calculates tax for the order. When `false`, no tax applies. Default: `true`. |
| `location` | Optional | [OrderTaxLocationRequest](../models/OrderTaxLocationRequest.md#ordertaxlocationrequest) | The address Flint calculates automatic tax at for items and charges without a fulfillment destination of their own. The tax location you supply for an order, as a postal code or a full address, with or without an address type. |

### OrderTaxRequest.delivery_charge_calculation

Percentage tax template copied onto every positive delivery charge generated by checkout, including paid pickup. Allowed only with external tax. Changing it leaves existing charges unchanged; use tax.charge_calculations to override those. A new selection copies the template again. Set it before issuing an invoice; the invoice freezes it with the order. A percentage tax template for the delivery charges checkout generates, including paid pickup: whether the charge includes the tax, and the tax components. Allowed only on orders that use external tax.

| Field | Presence | Type | Description |
| --- | --- | --- | --- |
| `components` | Required | Array of [TaxComponentRequest](../models/TaxComponentRequest.md#taxcomponentrequest) | The tax copied onto each delivery charge, one percentage component per jurisdiction and tax type. minItems: `1`. `components[]`: [field definitions](../models/DeliveryChargeTaxCalculationRequest.md#deliverychargetaxcalculationrequest-variant-2components). |
| `mode` | Optional | string | Optional. If you send it, it must be `external`, because delivery charge templates apply only to orders that use external tax. Values: `"external"`. |
| `price_mode` | Required | string | Whether the delivery charge already includes the tax. Values: `"additive"`, `"inclusive"`. |

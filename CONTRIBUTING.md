# Contributing

The Node.js/TypeScript and PHP SDKs in this repository are generated from Flint's pinned OpenAPI contract using [flint-pay/sdk-generator](https://github.com/flint-pay/sdk-generator).

We do not accept pull requests in this repository. Submit SDK fixes and improvements to the generator instead; maintainers regenerate and release the SDKs after upstream changes are incorporated. Direct edits to generated files will not be carried forward.

Read the [generator's contribution guide](https://github.com/flint-pay/sdk-generator/blob/main/CONTRIBUTING.md) before opening a pull request. For substantial changes, open an issue in the generator repository first to discuss the approach and scope.

For help integrating with Flint, see [Flint Pay's developer docs](https://developers.withflintpay.com/) and the package references in this repository: [Node.js/TypeScript](node/REFERENCE.md) and [PHP](php/REFERENCE.md).
